# OpenAPI contract

`openapi.json` is the contract between this repo and `nabhahita-frontend`.

- Regenerated by `pnpm openapi:export` (Nest `SwaggerModule.createDocument` → file, no server start). CI will fail on drift once wired.
- The frontend's `packages/api-client` generates a typed client from a **pinned** version of this file.
- API changes are **additive-first** (expand → migrate consumers → contract). Breaking changes bump the contract major and need an ADR note.
