# @nabhahita/engine-billing
Deterministic billing & payout engine: per-active-head monthly invoicing (contractor) and payouts (ESM),
driven by verification results. See ADR-0005 (money & ledger rules).
Worked example to pin first (Contractor Portal doc §4.5): 31 heads × ₹200 = ₹6,200; 12 × ₹200 = ₹2,400; GST as separate line.
